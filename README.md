# 302

宿舍恐怖冒险,用 [ink](https://www.inklestudios.com/ink/) 写成,靠 [Inkwright](https://github.com/luoxin9510/inkwright) 的游戏模式在 Obsidian 里玩:四位可选主角、2d6 检定、恐惧值、心声。

A dorm horror adventure in ink, played in Obsidian with the Inkwright plugin's game mode (four playable characters, 2d6 checks, fear, inner voices).

## 怎么玩 / How to play

1. 把这个仓库当作 Obsidian vault 打开。Open this folder as an Obsidian vault.
2. 安装社区插件 Inkwright。Install the Inkwright community plugin.
3. 打开 `main.ink`,点"试玩"。Open `main.ink` and hit Play.

剧本正在写。The script is in progress.
