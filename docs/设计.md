# 302 设计稿

2026-10-30 起草。本文记总的决定,demo 的具体大纲在 `demo.md`,随写作更新。

## 一句话

一个普通上学日的晚上,302 的四个人逃了晚自习躲在黑掉的宿舍里讲鬼故事;九点该下课了,没有人回来,这一层楼已经不是原来那一层。

## 已定的方向

- **类型:探索调查 + 生存战斗的传统文字冒险。** 一个基地、一张小地图、一间一间走,边查边活下来。不做规则怪谈,没有"照着做就安全"的规矩;没有搞笑路线。
- **结构:楼归档每一个进来的人。** 四位可选主角各走一遍同一栋楼,各自的经历是同一件事的碎片。不是"打败鬼",是弄明白这里发生过什么,然后出去。
- **开场:鬼故事之夜。** 一人讲一个这栋楼的怪谈;它们只是预告和传歪了的记忆,不是规矩。
- **转折:九点没人回来。** 门外有人问"几个人",之后这一层就是禁断空间:熟悉的地方,细节错了。
- **因果派。** 楼里埋着一桩旧事(以前一个逃晚自习没出去的学生),查清它是主线;物证要能拿在手里。
- **结局不靠仪式"消灭"。** 查明真相、带人出去;恐怖是底色,笑只来自失败后果、心声和室友斗嘴,不单独做喜剧结局。
- **别的 NPC 都没有好下场**:要么变异,要么惨死;全部化名。
- **别的恐怖宇宙可以乱入**:禁断空间接着别处闹鬼的地方,别处的鬼怪会出现。只用民间传说和公有领域的形象,不用有版权的角色。
- **战斗要有**:它有气势没有血,每回合选一个技能动作掷骰,打退就能走。

## 写作规范

- 每场戏有铺垫、暗示、突发、回味;前五分钟就要出现不对劲的东西;不藏前提。
- 高潮前不先说结论;目标要在故事层被接受,不只是系统层。
- 检定:失败必须改变点什么(变量或可选项),否则不掷;描述已经决定结果的也不掷。
- 选项分三类并心里有数:故事型(分岔)、参数型(改数值)、无意义型(只为扮演,少用)。
- 选项要有取舍:稳妥低收益对冒险高收益,别出现唯一正解。
- 正文双语 `{t("中文", "English")}`;id 和 ink 标识符全英文。
