# 《游戏剧本怎么写》学习笔记

佐佐木智广著。底稿是 cybrog-brain 里的 15 篇读书笔记(`notes/game-scripting/`),这里按书的章节顺序重新消化,每章末尾写"用到 302 上"。写人物之前先过第二、三章;写戏的时候回头翻第八到十一章。

## 0 序章:剧本是什么、给谁看

**书里说**

- 游戏剧本不是写给玩家看的,是写给一起做游戏的人看的:程序、美术、音乐、配音。它是一份信息文档,先求信息清楚,再求文笔。
- 编剧不从零开始:策划书先定游戏类型、主人公、游戏目的、系统,编剧在这个框里写。不理解系统写出来的剧本"统统不能用"(例:目标是打一百零一只魔兽,新人却写了一整篇男女感情)。
- 流程:先写三到五行的"情节",一次写五个让人挑;定了方向再用序破急扩成一张 A4 的骨架;然后才是剧本。
- 剧本格式:台词和描写分开写;每场标时间地点;背景、音乐、动画、翻页都有编号和标记。格式因工作室而异,进了门自然会。
- 对甲方:不是照单全收,也不能拿"按你说的做的"当挡箭牌。

**用到 302 上**

- 我们的"策划书"就是 `设计.md` 加 `game.md`:系统是 2d6 检定、恐惧、队友信任、物品、一小时一处、天亮前八小时。写任何一场戏先问:它用到了哪个系统?恐惧动了吗?时间走了吗?
- 我们的"格式"是 ink:`#check`、`#voice`、`#fx`、`#needs` 就是书里的"指示",面板会读;正文是旁白,引号里是台词。
- 一场新戏先写三到五行情节,再扩 A4 骨架,再写 ink。别直接下笔写 ink。

## 1 主题与故事

**书里说**

- 主题是给整个游戏定方向的一个词或一句话。单词型("复仇""友情")像旗帜;长句型("能逃出丧尸横行的大宅吗""主人公是菜鸟律师会怎样")自带驱动力,疑问句尤其好。
- 故事是用来表达主题的东西。主题答"这游戏关于什么",故事答"发生了什么"。
- 主题必须和游戏目的绑在一起,否则越追主题越偏离玩法。办法:找到目的的关键对象,和主题建立因果。
- 主题太抽象就加修饰词:"毅力"→"画家的毅力"。
- 从主题推故事:连着问"为什么""然后呢"。
- **主题不写在台词里。** 角色一说"家人最重要"玩家就出戏。两种表现法:一是让主题变成选项(爱与正义:告发、嫁祸、牵手逃跑,三个选项就是主题本身);二是让故事按选择往不同方向发展,前面的积累影响后面同一个选项的结果。

**用到 302 上**

- 我们的主题是疑问句型:"四个人住的 302,能四个人一起走出去吗。"这和游戏目的(天亮前出去)是绑死的。
- 母题:数数、四、位子。它们不许被任何人说破;要在选项里被体验:是替怡把名字写回去,还是把登记本带走当钥匙。
- 每写一场,问一句:这一场的选项有没有一个在体验"四个人一起"?

## 2 角色创作

**书里说**

- 角色 = 有个性、目的、意志、感情,并照着它们行动的个体。推动故事的原动力是角色的目的和意志;编剧的水平就看能不能把目的写重、把奔向目的的过程写活。
- 纠葛是意志和感情的放大器。外在纠葛:战斗、对立;内在纠葛:两种想要的撕裂。悬崖的例子:只有恋人时选项不撕裂(都是为她好),加一个孩子,放手救孩子和不放手救恋人才真撕。
- 角色三要点:有魅力有个性(设定);定位不重复(定位);目的意志感情都和故事挂钩(关联)。
- **角色设定表**:给画师和给自己的接口文档。字段和要点:
  - 名字:靠发音而非意思左右印象(d/g 音像恶人,n 温柔,p 俏皮,t 主角感)。
  - 年龄:标出角色之间的大小关系,借用年龄自带的社会印象。
  - 职业/身份:自带先入印象,可顺用也可反用。
  - 相貌、头发、体格、服装:只写和故事有关的;头发和服装是"从外面把握角色"的捷径,发型变了说明人变了。
  - 性格:要同时写成因,台词才有深度。
  - 特技:凸显和别人的不同,后面总能派上用场。
  - 弱点:代入感的入口,弱点让人亲近。
  - 口吻:区分角色的石蕊试纸。两个人口吻一样,设定八成重复了。
  - 剧本上的设定:目的、过去、现状。
- 不要靠"你肯定懂"传递信息:画师问"狼是四条腿还是两条腿,穿不穿衣服"。所有和故事有关的都写进表里。
- **定位型性格**:"父亲般""哥哥般"这种集体里的固有印象。三种用法:顺用(爷爷通灵比父亲通灵可信)、反差(平时像母亲的父亲关键时刻像父亲)、成长(从弟弟般变成哥哥般)。

**用到 302 上**

- 四个人每人一张表,NPC(宿管阿姨、阿泽、小冯、大头)各一张短表。字段见文末模板。
- 302 没有画师,但有 `#voice` 和队友数值:表里要多两栏,"怕的时候怎么样"和"信任高低时怎么样",这是我们这个系统的"相貌"。
- 口吻是重点:四个男生,口吻一样就全完了。表里要写到句式层面(短句还是长句、爱问还是爱断言、口头禅)。
- 纠葛要设计成"两样都想要":救怡的位子还是省时间;带走登记本(钥匙)还是把它留给阿姨。

## 3 角色定位

**书里说**

- 定位是角色在故事里的立场和功能,设定是角色是谁。食材是设定,谁是主菜是定位。
- **角色重复是定位重复,不是外观重复。** C-3PO 和 R2-D2 外观一样但一捧一逗,不重复;欧比旺和尤达外观不同但都是贤者,欧比旺就弱了。
- 一个角色可以兼多个定位;定位可以随故事变(比克:恶人→竞争者→贤者)。定位的变化本身就是成长弧。
- 五大类定位:
  1. 和系统有关:主人公、待攻克对象、系统角色(引导员、商人)。
  2. 对立:恶人/敌对、难关、竞争者。
  3. 同阵营:情侣、伙伴、家人。既是助力也是枷锁。
  4. 让故事转弯:契机、救星、叛徒、贤者。
  5. 补充强化:缓冲(丑角)、深论(替玩家问"这怎么可能")、动物(用反应标好坏)、闲杂。
- 主人公两种:换位型(贴近玩家,个性淡,台词少,用选项代替性格)和角色扮演型(个性强,玩家去贴近他;风险是他做出玩家不接受的事)。
- 伙伴三功能:战友(有主角没有的能力,"需求是伙伴之母")、倾听者(让主角把心里话说出来)、衬托(用反差或自身魅力烘托主角)。要点:别写成"好好先生",让伙伴会说"不";别让伙伴变成"死角色",激活靠牺牲或变脸。
- 家人:登场就有存在感,但不给戏份会自然衰减。
- 难关角色过了关要重新给定位,否则"挂起"。
- 贤者:知道主角和玩家不知道的事;不亲自行动(动了就不是贤者);可以替编剧说话。
- 叛徒:冲击力和信任深度成正比;另立一个"看着像叛徒"的当障眼法。
- 契机:推理故事里的被害者就是契机;被害者要么可怜要么该死。
- 动机分个人层面和社会层面:个人的("右臂被变成植物,要让它恢复")促进代入;社会的("身为总统要保护国家")弱。蜘蛛侠两条都有,观众代入的是守护意中人。
- 同一套角色换主人公就是另一个故事:桃太郎、辉夜姬、食人魔三种主角三个故事。定位分配是从角色到故事的桥。

**用到 302 上**

- 昕是换位型主人公:台词少,心声多,靠选项定性格。玩家要能把自己放进去。
- 三个队友分三个定位,不许重复:
  - 志勇:逗哏 + 战友(力量) + 会说"不"的伙伴。缓冲角色也是他。
  - 烟波:捧哏 + 倾听者 + 深论(替玩家问"这说不通")。
  - 怡:被契机选中的人(位子被清掉)+ 讲道理的那个;他的"位子"是全队的枷锁。
- 待攻克对象是这栋楼/第八扇门;阿泽是难关兼贤者兼契机,阿姨是系统角色(登记、钥匙)兼贤者兼可能的叛徒(她的登记本是钥匙,她知道的比说的多)。小冯和大头是闲杂兼契机:他们是"没好下场的别人"。
- 四人不拆伙,所以牺牲这招不能用在四人身上;激活靠变脸:怡被清掉后从讲道理变成什么?烟波什么时候第一次不捧而是说"不"?
- 每个人的动机写个人层面的:不是"要活着出去",是"要把怡的鞋找回来""手机还有 12% 电要给家里发条消息"这种。

## 4 世界

**书里说**

- 世界 = 时间 + 地点,再向外长出一切:生活形态、科技、法则。
- 起点是"如果世界是这样的呢"。世界设定表只列必须的项,不求全。
- 规则一致才有真实感;再荒诞的设定,规则自洽玩家就接受;规则打架玩家立刻出戏。
- 游戏系统就是世界的物理法则:伤害、概率、能做不能做。过场里摔死、游戏里跳三楼没事,这就是破绽。
- 世界生成"形象"(帝国→公主),形象给角色设定参照,也给反差提供背景(奇幻世界里"胆小的剑士"成立,现代就不成立)。
- 主题、故事、角色、世界四者互联,写的时候在四者间来回跳。

**用到 302 上**

- 我们的"如果":如果一栋宿舍楼晚上多出一扇门,四个人住的房间只认三个人。
- 楼的规则要定死并守住:一小时一处;楼认"数";天亮它停;登记本能开门;位子被清掉的人人还在。规则列在 `设计.md`,新戏不许违反,违反就得改规则不能改一场。
- 系统即法则:恐惧满了会怎样、队友信任低了会怎样,这些数值行为就是这栋楼的物理,写出来要和数值一致。
- "形象":大学宿舍自带的形象是宿管阿姨、查寝、熄灯、晾衣杆、充电宝、泡面。角色反差从这里来。

## 5–7 结构

**书里说**

- 结构是"传递信息时最容易给人留印象的排列方式",不是内容本身。剧本写不完多半是没结构。
- 起承转合、序破急、三幕式说的是一回事:开头、发展、结尾。游戏多一样:分支(选项和失败)。
- 四要素:
  - 开端:传达游戏目的、怎么玩、这是个什么游戏(谁是谁、什么关系)。无懈可击。
  - 通往高潮的过程:占八成以上,最费脑子。先定义"失败在故事里是什么意思"。章节四类:达成目的的(设障碍/给援助)、推进剧情的(事件)、加深主题的(给事件情感厚度)、偏离目的的(小乐趣)。最好一章兼几类。
  - 高潮:达成目的的瞬间,把前面的时间精力感情一次释放。高潮成败全由过程决定,不是高潮本身怎么写。
  - 结局:说明达成之后世界和人怎么变了。有"真结束"和"你还没看到真结局"两种 game over。重玩机制允许大胆:开场三分钟就能死,玩家靠死学规则。
- 好结构的三条:传达目的(系统层和故事层都要接受)、促进感情代入(按顺序透露)、挑起对高潮的饥饿(弓拉满再放,拉过头弓就坏了)。
- 钓鱼的故事:同样的事,先说结论对方只会"哦";先说目的、再障碍、再要放弃、再转折、再悬念、最后结论,对方会"真棒"。八步:知道目的→疑问→代入→意外→期待→期待到顶→结论→回味(此时给具体数字"82 厘米"最有说服力)。
- **结论不能先说。** 这是最常见的坏结构。

**用到 302 上**

- 开端(第一场)三件事检查:目的(天亮前出去)、玩法(检定、恐惧、时间)、这是什么游戏(四个人、302、楼不对劲)。目前第一场有没有把"四个人一起"的目的在故事层立住?
- 失败的定义:我们没有死亡,失败是时间没了(天亮没出去)或人没了位子。每场戏的失败分支要回答"失败在故事里是什么",不只是恐惧 +20。
- 第三场的每个地点标一下它是哪类章节:水房是推进(线索)兼加深(小冯的下场预告四人的命运);值班室是达成(钥匙、登记本)兼加深(怡的名字)。偏离目的的小乐趣我们几乎没有,可以在走廊等待里放一点。
- 高潮是第八扇门。它成不成,看前面七个小时有没有让玩家在乎这三个人。所以人物描写排在前面是对的。
- 结局要写变化:出去之后谁变了什么。回味处给一个具体的东西(登记本上多出的一行、手机电量的数字)。

## 8 选项

**书里说**

- 选项是给玩家脑中的问题准备的两个以上答案。玩家不选游戏不走,这种"游戏在等我"是参与感的来源;自己选的后果自己担,这是乐趣的来源。
- 自由是"创作者手心里的自由"。目标不是无限选项,是让玩家感觉不到边界。
- **黄线法则**:画面上有黄线,选项里就得有"剪黄线",哪怕没意义。玩家看到"该有却没有"的选项就出戏。两条铁则:没有破绽,不给玩家压力。
- 三类选项:故事型(改走向)、参数型(改数值,延迟生效)、无意义型(调节气氛,少用)。
- 两条设计原则:选择基准要明确("徒步 vs 坐公交",不是"吧嗒 vs 啪嗒");结果要有必然性(温柔→好结局符合常识,反过来要先铺设定)。
- 出现时机:放在结构转折点(开端→过程、过程→高潮);放在强烈情感事件处,让不同玩家选不同的行动,而且选项写行动不写情绪("向他冲过去 / 跪倒 / 咯咯笑",不是"被愤怒支配 / 被悲伤支配")。
- 标志(flag)系统:分支靠它;规模一大必须编号建表,bug 多出在标志管理。

**用到 302 上**

- 每个地点写完,把正文里出现过的东西列一遍,看选项里有没有漏(正文写了晾衣杆,选项里就得能拿晾衣杆)。
- 选项写动作:"把名字写回去""带走登记本""回走廊",不写"决定帮怡"。
- 恐惧飙升处放选项,让玩家选"怎么怕":冲出去、蹲下、笑出来。这比旁白写"你怕极了"强,也是心声派上用场的地方。
- 我们的 flag 已经不少(went_*、*_known、erased、noticed…),`设计.md` 里要维护一张变量表,写新戏先查表。

## 9 节奏

**书里说**

- 开端 hook:主人公受动型(平凡人被卷入,要靠情感触发接住大使命)或开拓型(一开始就有目标;推理、恐怖多是这种)。救猫咪:开头让主角做一件让人站他这边的小事。
- 前置信息不能写成说明书:藏进事件和对话里(女剑士认错人、拔刀、被徒手卸械,四条信息一场戏传完)。
- 场景序列:把要花时间的场景写成有序破急的小故事,尤其是开头结尾、最终战、容易单调的移动。
- 支线 = 人物关系的变化;要有自己的序破急,要和主线绑死,不能喧宾夺主。
- 伏笔:让后面的转折不突兀,事实、台词、道具都能当伏笔。
- 下饵:留一个谜等后面揭,只能设在故事需要的地方。
- 预告:先让人看到一点,再让它发生,"要来了"比"来了"有效。
- 假动作:让人以为是 A,其实是 B;进阶是假高潮(打完 boss 发现另有黑手)。
- 回想开场:用结局时点的一句感慨开篇,后面全部笼罩在"肯定要出事"里。

**用到 302 上**

- 第一场要有昕的救猫咪时刻,很小就行:给怡递纸巾,替志勇背锅。
- 四个人的性格和关系全部用事件和对话交代,不许旁白介绍"志勇是个粗人"。
- corridor_walk 就是场景序列:每次走廊都要有自己的小弧线,不能只是遇伏骰一次。
- 支线 = 队友信任和怡的位子,已经和主线绑着(登记本既开门也写名字),保持。
- 可以考虑回想开场的变体:开场一句"后来我们谁都没再提那天晚上数到几"。

## 10–11 文字:台词与旁白

**书里说**

- 文字三类:台词(角色说的)、旁白(玩家看得见的叙述)、指示(给开发看的)。
- 台词三功能:表达感情、说明情况、推进故事。说明情况的台词越少越好。
- 旁白五功能:事实、心理、看得见的东西、时间、推进。时间可以用递减的省略号表现,是游戏独有的写法。
- 台词的外观:多长一屏、在哪换行翻页都影响节奏;翻页可以制造"挨了一拳"的停顿。知道规范才能有意识地打破。
- 表情、语境、情景决定台词的意思;言外之意比字面多;敬语和称呼显示关系,反着用是讽刺。
- 台词能顺带显示时代、出身、年龄,靠措辞和句尾。
- 写台词四大病:太长、说明性太强、缺动作、读不出感情。治法:一屏放下;一句一信息,拆进来回;边做边说;前三样治好感情自然出来。
- 最想传达的放句尾;出声朗读;捧哏逗哏(捧哏比逗哏难,捧得晚一点还能顺带显示上下级)。

**用到 302 上**

- 这部分已经整理进 `写作.md`。写人物时直接用来定口吻:每个人一条"句式 + 口头禅 + 他怎么说明情况(爱不爱解释)"。

## 302 角色设定表(模板)

按书的字段,加上我们系统需要的。四个人各一张,NPC 用短版。

```
名字 / 化名:          (发音给人的感觉)
年龄 / 年级:          (和其他人的大小关系)
身份:                 (宿舍里的角色:谁管钥匙、谁晚睡、谁做饭)
外形:                 (只写和故事有关的两三样:身高、眼镜、拖鞋、袜子)
服装 / 随身:          (那天晚上穿什么、带什么;开局物品)
性格:                 (倾向 + 成因,一句话成因)
特技:                 (对应技能等级最高的那项,具体到能做什么)
弱点:                 (让人亲近的那种;对应技能最低的那项)
口吻:                 (句式长短、爱问还是爱断言、口头禅、怎么称呼别人)
定位:                 (主/伙伴/倾听/捧逗/契机/贤者…可以几个;会不会变)
个人层面的动机:       (今晚他自己要的那一样,不是"活着出去")
怕的时候:             (恐惧 30 / 60 / 90 各一句他会做什么、说什么)
信任高 / 低时:        (对昕的态度怎么变,各一句)
想要 vs 想要:         (他的内在纠葛,两样都想要的是什么)
和另外三人的关系:     (每人一句,含私底下怎么叫对方)
剧本上的设定:         (过去、现状、他和这栋楼/阿泽有没有关系)
不说破的事:           (他知道但不会主动说的)
```

NPC 短版:名字、身份、定位、他要什么、他的下场、口吻一句、他和楼的关系。
