# Demo:一个晚上

2026-10-30 讨论定稿。demo 的目标是把"引擎 + ink + 剧本"打通一次,不是把故事写完。整个游戏发生在一个普通上学日的晚上。

## 类型

探索调查 + 生存战斗的传统文字冒险:一个基地,一张小地图,一间一间走,边查边活下来。不做规则怪谈,没有"照着做就安全"的规矩;没有搞笑路线。

## 前提

老师不查寝,但晚上 6:30 到 9:00 要上晚自习。302 的四个人逃了,代价是不能开大灯,免得被楼外看见。楼空了,屋黑了,他们决定看鬼片或者讲鬼故事。

大灯只是把楼弄黑的引子,不是规矩。

## 核心体验

躲在黑掉的宿舍楼里,一个地方一个地方走,查清这层楼发生过什么,天亮前把人都带出去。

## 玩家整晚在干什么

从 302 出发,在这一层楼里走。每个地方都有三样东西:能找到的线索或道具、可能碰上的危险、要付的代价(时间、电量、恐惧)。

## 时间线

1. 6:30 全楼去上晚自习,302 四个人关了大灯,放片子或讲故事。四个鬼故事在这里讲完,它们只是预告。
2. 讲到一半,楼里有动静,笑过去。
3. 9:00 该下课了,走廊里该有人回来了。没有人回来。时间停在 8:59。
4. 门响了,门外问"几个人"。门外安静之后,这一层已经不是原来那一层。这是进入禁断空间的时刻,怎么答都会进来,区别是进来之后少了谁、多了谁。
5. 有人受不了去开大灯:灯亮了,屋子看着不一样。玩家第一次确认出不去了。
6. 探索与调查,碰上它,碰上别的人。
7. 天亮前,第八扇门。
8. 天亮,结局看谁出去了。

## 禁断空间

就是这一层楼,但不对劲了。走廊还是那条走廊,细节错了:楼梯下到底还是这一层;窗外是黑的,或者映出来的是走廊自己;手机没信号;时钟不走。不是奇幻异界,是熟悉的地方错了。

## 地图(七个地方)

| 地方 | 有什么 | 危险 |
|---|---|---|
| 302 | 基地,可以回来喘口气,每次回来都有点不一样 | 门外的敲门声 |
| 走廊 | 连接一切 | 最容易碰上它 |
| 水房 | 一条线索;水龙头自己开 | 第二场战斗 |
| 三楼厕所 | 最里面那格,一条线索 | 有东西应声 |
| 楼梯间 | 下到底还是这一层 | 让玩家确认出不去 |
| 宿管值班室 | 没人;登记本,302 那行有个被划掉的名字 | |
| 303 | 封住的屋子,要钥匙;以前那个住客的东西 | |
| 第八扇门 | 出口,最后才能开 | 第三场战斗 |

## 查什么

这层楼以前有个学生,也是逃了晚自习躲在宿舍,然后就没出去。登记本上他的名字被划掉,303 封了。四个鬼故事其实都是他的事传歪了的版本。把这些拼起来,才知道第八扇门怎么开、它要什么。

## 乱入的东西

进了禁断空间,就不只是这栋楼的鬼了:这一层接着别的闹鬼的地方,别处的鬼怪会乱入。用法:

- 当"客串"的对手或过客,让探索每次碰到的东西不一样;楼本身的它和以前那个住客仍是主线。
- 只用民间传说和公有领域的形象(花子さん、口裂け女、テケテケ、僵尸、冥婚、山村祭祀的东西、宇宙恐怖的真菌之类),不用有版权的角色,仓库是公开的。
- 每个乱入的东西带着它原来那个世界的味道(校园怪谈、港产僵尸片、日式村落、克苏鲁),玩家能认出来会很开心,认不出来也不影响。
- demo 里放一个就够,比如水房那场的对手。

## 别的人(NPC)

楼里不止他们四个:别的屋也有逃晚自习的,或者有留在楼里的人。这些人全都没有好下场,要么变异,要么惨死。变异的人可以成为战斗的对手,惨死的人留下线索或道具。全部用化名。

## 生存系统

- 恐惧(0 到 100):心理血条,满了会崩,一场戏失控。
- 体力(0 到 10):身体血条,归零倒下,要人拖。
- 手机电量(0 到 100):就是光,也是时间。黑着走更吓人,恐惧涨得快。
- 时间:每去一个地方,时钟往前走半小时。天亮前只够走六七个地方,去哪不去哪要选,留二周目的余地。
- 道具:晾衣杆、303 的钥匙、打火机、登记本。有道具,战斗里才多出动作。
- 队友:各有恐惧和对主角的信任。信任高跟你走并帮忙,恐惧高会跑或僵住,各有一件擅长的事。

## 战斗

它有"气势"而不是血。每回合它先动,你选一个动作,掷骰:

- 力量:砸它、顶开它。
- 耐力:顶住门、撑过这一回合。
- 魅力:稳住快崩的队友。
- 洞察力:看出它的破绽。
- 理智:压住恐惧,想起线索。

打退它就能走;打不赢就被压制,掉体力、涨恐惧。不是它死,是你能走了。三场:走廊第一次碰上,教会玩家硬打只能换时间;水房护着一个人(对手可以是变异的 NPC);第八扇门前最后一场,要道具和队友配合才开得了门。demo 先做前两场。

## 鬼故事的作用

开头四个故事只是预告。走到厕所最里面那格、看到多出来的门、听到水龙头、门外有人问几个人,玩家会认出"这就是那个故事"。

## 结局

- 四个人都出去了。
- 有人留下了。
- 都没出去,第二年 302 多了一个故事。

## 体量

一次通关 20 到 30 分钟,6 到 8 场戏,三个结局。四个主角共用场景,用 `{character == xin: …}` 做差异,技能差异靠成功率体现。先写开头(6:30 到敲门)跑通,再写探索和战斗。
