# Demo:一个晚上

2026-10-30 讨论定稿。demo 的目标是把"引擎 + ink + 剧本"打通一次,不是把故事写完。整个游戏发生在一个普通上学日的晚上。

## 类型

探索调查 + 生存战斗的传统文字冒险:一个基地,一张小地图,一间一间走,边查边活下来。不做规则怪谈,没有"照着做就安全"的规矩;没有搞笑路线。

## 前提

老师不查寝,但晚上 6:30 到 9:00 要上晚自习。302 的四个人逃了,代价是不能开大灯,免得被楼外看见。楼空了,屋黑了,他们决定看鬼片或者讲鬼故事。

大灯只是把楼弄黑的引子,不是规矩。

## 核心体验

躲在黑掉的宿舍楼里,一个地方一个地方走,查清这层楼发生过什么,天亮前把人都带出去。

## 玩家整晚在干什么

从 302 出发,在这一层楼里走。每个地方都有三样东西:能找到的线索或道具、可能碰上的危险、要付的代价(时间、电量、恐惧)。

## 时间线

1. 6:30 全楼去上晚自习,302 四个人关了大灯,放片子或讲故事。四个鬼故事在这里讲完,它们只是预告。
2. 讲到一半,楼里有动静,笑过去。
3. 9:00 该下课了,走廊里该有人回来了。没有人回来。时间停在 8:59。
4. 门响了,门外问"几个人"。门外安静之后,这一层已经不是原来那一层。这是进入禁断空间的时刻,怎么答都会进来,区别是进来之后少了谁、多了谁。
5. 有人受不了去开大灯:灯亮了,屋子看着不一样。玩家第一次确认出不去了。
6. 探索与调查,碰上它,碰上别的人。
7. 天亮前,第八扇门。
8. 天亮,结局看谁出去了。

## 禁断空间

就是这一层楼,但不对劲了。走廊还是那条走廊,细节错了:楼梯下到底还是这一层;窗外是黑的,或者映出来的是走廊自己;手机没信号;时钟不走。不是奇幻异界,是熟悉的地方错了。

## 地图(七个地方)

从 302 出发,走廊是去哪儿都要过的路;去一个地方算一个小时,天亮前一共八个小时(状态栏“天亮前”)。每个地方三样东西:线索或道具、危险、代价。

| 地方 | 有什么 | 危险 |
|---|---|---|
| 302 | 基地。回来恐惧降 10,但每次回来屋里变一样东西:钟跳到 9:00 又跳回去;门口多一双鞋(怡被清掉的话是他的鞋,鞋尖朝屋里);窗里映出的走廊有人站在 302 门口。门外会再敲一次问几个人,这次能答对(五个)。 | 开过大灯或开过门(marked)的话它知道这间屋,回来不再安全 |
| 走廊 | 必经。第一次出门就是第一场战斗:看不清、只听得见,它数数。没数过门的人这一趟自动数到第八扇。 | 它。打退只换一个小时;越晚越容易碰上 |
| 水房 | 池子里泡着第五件校服,领口有学号,对登记本用。304 逃晚自习的两个学生躲在这儿:小冯已经没了,大头吓傻了,要护着他出来。 | 第二场战斗,对手是乱入的皿屋敷阿菊(见下) |
| 三楼厕所 | 最里面那格敲三下有人应,应的是阿泽的声音,念那晚的数;隔板上刻着“正”字,是他躲了多少天;地上有打火机。 | 敲第四下它就来 |
| 楼梯间 | 往下走到底还是三楼;往上一层反而是一楼大厅和值班室(楼是反的)。墙上封条日期和 303 一样,给出年份。楼上永远有阿姨的脚步声,比你高一层。 | 不可名状的东西在这里(见下);多走吃时间 |
| 宿管值班室 | 没人,茶杯是热的,拖鞋还在。登记本:302 那行划掉的旧名字(阿泽);今晚来访页上志勇、怡之外有第五个名字,笔迹不同;怡被清掉那条线上怡的名字也被划了。钥匙柜里 303 的钥匙缺了。窗外能看见宿舍楼,全黑,只有 302 亮着。 | 没有 |
| 303 | 要钥匙,或者力量破门(动静引它来)。楼的档案库:阿泽的床原样留着,墙边摆着历年没出去的人的东西(怡被清掉的话他的鞋也在)。拿到阿泽的学生证,这是能拿在手里的物证。阿泽在队里的话,他在这里认出自己的床。 | 它在这里最浓 |
| 第八扇门 | 出口。要数过门、要学生证、要队友配合。门外最后一次问几个人,答五个,门开。 | 第三场战斗(demo 先简化) |

## 查什么

这层楼以前有个学生,阿泽(化名),住 303。有一年他也是串门到 302 躲晚自习,门外问几个人,屋里答了四个,门外说不对、五个。他没出去,楼把他归了档:登记本上 302 那行他的名字被划掉,303 封了。四个鬼故事全是这件事传歪的版本。

门外的数一直是对的:它数的是“这屋该有几个人”,阿泽始终算在 302 里。今晚四个人进来,它说五个,就是这个意思。要出去得让数对上:把阿泽“签出去”(学生证或登记本带在手里,门口答五个),或者留一个人顶他的位子。

第二场三条分支进了探索各有用处:怡被清掉(erased)是阿泽遭遇的重演,他恐惧最高,到 303 看见自己的鞋会想留下,要用魅力拉他;怡被跳过(hidden)是它数不到他,他能在它面前拿钥匙、开 303 不被发现,代价是门口答数时他不算数,出门差点被关在里面;多出阿泽(fifth)是他本人回到了那晚的屋里,不说话,跟着走,别人当他一直在,在 303 认出自己的床。

## 乱入的东西

进了禁断空间,就不只是这栋楼的鬼了:这一层接着别的闹鬼的地方,别处的鬼怪会乱入。楼本身的它和阿泽仍是主线,乱入的是客串的对手或过客,让每次碰到的东西不一样。

- 用日本恐怖里有名的鬼怪(民间传说和公有领域的形象:皿屋敷的阿菊、花子さん、口裂け女、テケテケ、四谷怪谈的阿岩、雪女),再加克苏鲁式的不可名状。不用有版权的角色(贞子、伽椰子之类),仓库是公开的。
- 每个乱入的东西带着它原来那个世界的味道,玩家认出来会很开心,认不出来也不影响;昕恐怖片看得多,可以由他认出来。
- demo 里放两个:水房是皿屋敷的阿菊——井边数盘子的鬼到了水房的池边,一边洗一边数,数到九少一个,就回头数人;排水口那圈白的东西是盘子的碎末。楼梯间是不可名状:楼梯下到底还是这一层、往上反而到一楼,楼梯间的窗外没有天,有很大的东西在动,看见了也说不出形状,理智检定失败掉恐惧。
- 志勇讲的“敲三下有人应”本来就是花子さん那一型,厕所那格是本楼自己的版本,应声的是阿泽。

## 别的人(NPC)

楼里不止他们四个:别的屋也有逃晚自习的,或者有留在楼里的人。这些人全都没有好下场。全部用化名。

- 小冯(304):躲在水房,被阿菊数进去了,脸朝下在池子里。留下线索(校服学号)。
- 大头(304):吓傻了,躲在水房隔间。护着他出来是水房那场的目标;他后面还是没出去(楼梯间或第八扇门前),怎么没的待写。
- 宿管阿姨:值班室茶杯还热,人没了。她去“上楼”了,在楼梯间永远比你高一层;最后在第八扇门后看见她的背影——她也是没出去的人。

## 生存系统

- 恐惧(0 到 100):心理血条,满了会崩,一场戏失控。
- 体力(0 到 10):身体血条,归零倒下,要人拖。
- 手机电量(0 到 100):就是光,也是时间。黑着走更吓人,恐惧涨得快。
- 时间:每去一个地方(含回 302)一个小时,从 9:00 到 5:00 共八个小时,状态栏“天亮前”倒数;墙上的钟一直 8:59,只有手机的表在走。只够走六七个地方,去哪不去哪要选,留二周目的余地。战斗输了再丢一个小时。
- 道具:晾衣杆、辣椒面、充电宝(充一次电)、303 的钥匙、打火机、阿泽的学生证、登记本。有道具,战斗里才多出动作;第八扇门要学生证(`#needs:card`)。
- 队友:各有恐惧和对主角的信任。信任高跟你走并帮忙,恐惧高会跑或僵住,各有一件擅长的事。

## 战斗

它有"气势"而不是血。每回合它先动,你选一个动作,掷骰:

- 力量:砸它、顶开它。
- 耐力:顶住门、撑过这一回合。
- 魅力:稳住快崩的队友。
- 洞察力:看出它的破绽。
- 理智:压住恐惧,想起线索。

它的气势是个数(走廊第一战 3)。每回合它先数一个数:第一下吓人,第二下志勇挡(信任够、他不太怕的话),之后每下掉体力。然后你选一个动作掷骰:砸(力量)、晾衣杆捅(力量,容易些,要杆)、顶住(耐力,下一下不掉体力)、稳住队友(魅力,志勇出手、怡睁眼)、看破绽(洞察,难;看出它数数要停)、报错的数(理智,看出破绽后才有;它从头数,气势掉 2)、压住恐惧(理智)、撒辣椒面(要辣椒面,消耗)、跑回 302(掉体力涨恐惧)。气势归零它退回最后那扇门,走一个小时;体力到 2 或恐惧到 90 就被它穿过去,拖回 302,再丢一个小时。

不是它死,是你能走了。三场:走廊第一次碰上,教会玩家硬打只能换时间;水房护着大头,对手是阿菊;第八扇门前最后一场,要学生证和队友配合才开得了门。demo 先做前两场。

## 鬼故事的作用

开头四个故事只是预告。走到厕所最里面那格、看到多出来的门、听到水龙头、门外有人问几个人,玩家会认出"这就是那个故事"。

## 结局

- 四个人都出去了:带着学生证(或登记本)在门口答对数,天亮后 303 的封条没了。
- 阿泽留下了:他跟到门口,出不去;四个人出去,数对了。队友不拆伙,留下的只会是他。
- 都没出去:天亮前没开门,第二年 302 多了一个故事,烟波讲的。
- 二周目钩子:被楼记住的人(marked)出去以后,门外还会有人问几个人。

## 体量

一次通关 20 到 30 分钟,6 到 8 场戏,三个结局。玩家只扮演昕,另外三人是队友(他们的恐惧和信任在面板上看得到)。先写开头(6:30 到敲门)跑通,再写探索和战斗。2026-10-31:第一、二场写完;第三场的基地、走廊和第一场战斗写在 `scene3.ink`,六个地方还是占位。
