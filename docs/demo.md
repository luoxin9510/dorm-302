# Demo:一个晚上

2026-10-30 起草。demo 的目标是把"引擎 + ink + 剧本"打通一次,不是把故事写完。整个游戏发生在一个晚上:熄灯开始讲怪谈,天亮结束。

## 核心体验

挤在熄灯后的宿舍里和室友讲鬼故事,讲着讲着发现故事是真的,天亮之前要把人保住。

怕是底色,笑是花:笑来自失败的后果、心声的吐槽和室友斗嘴,不来自破坏恐怖本身。

## 玩家一进来就知道的事

- 这是闹鬼的楼(不藏前提)。
- 目标:撑到天亮,四个人都在。
- 开拓型主人公:昕一开始就有事要做(安抚、查、决定),不需要等世界来找他。
- 前五分钟就要有一件不对劲的小事,发生在第一个怪谈讲到一半的时候。

## 时间线:序破急

一个晚上切成三段,每段有自己的小弧线(序破急套序破急)。

**序 熄灯到午夜(约 22:30 到 00:00)——怪谈之夜**

- 查寝走了,四个人没睡,有人提议讲鬼故事,一人一个,讲的都是这栋楼的怪谈。
- 每个怪谈说出这栋楼的一条规则:哪里不能去、几点以后不能做什么、听到什么不要应。四个怪谈合起来就是这栋楼的禁区地图,后面的检定都从这些规则来。
- 救猫咪:讲故事的间隙给昕一个小善举的机会(给怕黑的那位留一盏灯,帮人圆场),让玩家先喜欢上这个人。
- 前置信息全藏在怪谈和拌嘴里,不写说明文。
- 第一个不对劲:某个怪谈讲到一半,故事里描述的声音或东西在现实里出现了一下(水房的水声、走廊一下敲门、晾衣绳上多出来的东西),大家笑过去,玩家记住了。

**破 午夜到凌晨三点——应验**

- 轮到最后一个怪谈,讲到一半,故事里的事真的开始发生。讲的人停下来,讲不下去。
- 调查:走廊、水房、三楼厕所、楼梯间,每处对应一条怪谈规则。守规则就安全,破规则才能拿到线索——这就是三角性:稳妥没收获,冒险才有东西。
- 物证:一件能拿在手里的旧东西(旧的住宿登记本、一张压在床板下的纸、封起来的门后面的东西),上面写着这栋楼埋掉的旧事,也写着 302。
- 中段高潮:第一次有人"被带走"或者"差点被带走"。
- 四个主角的碎片在这里体现:昕在走廊看到的,怡在房间里听到的,烟波从登记本上读到的,志勇在楼梯间碰到的,是同一件事的四面。demo 里用同一场戏加 `{character == xin: …}` 的分支做差异,不写四套剧本。

**急 三点到天亮——决断**

- 弄明白规则之后能做什么:不是消灭,是用规则保人(该应的不应、该开的门不开、该留的灯留着)。
- 一个红检定放在这里:失败也要往前走,只是代价不同。
- 结局 3 到 4 个:四人都在;有人没了但知道了真相;守住了人但没弄明白,怪谈明天继续;一个喜剧向的"原来是……"结局可以留给失败路线。
- 归档的揭示放在最后:登记本的下一页已经写着今晚的日期。

## 四个怪谈(候选,选四个,定一个应验)

都是校园怪谈改到宿舍楼里,每条自带一个规则和一个检定点。

1. **三楼厕所最里面一格。** 熄灯后敲三下会有人应。规则:别去。检定:要不要去确认(洞察,看出格门下面的影子不对)。
2. **查寝。** 熄灯后再有人敲门问"几个人",必须答对人数。规则:别答错。检定:理智,数清楚屋里到底几个人。这是二选一都危险那类,适合做转折。
3. **多出来的一扇门。** 走廊尽头的门,白天数是七扇,半夜数是八扇。规则:别数。检定:耐力,走过去不回头。
4. **水房的水龙头。** 半夜自己开,水声像有人在洗东西。规则:别去关。检定:力量,拧得上;或者魅力,劝室友别去。
5. **晾衣绳上多出来的衣服。** 阳台晾衣绳上多了一件谁都不认识的校服。规则:别收。检定:洞察,看出它是湿的。
6. **302 之前的人。** 这间屋以前住过一个人,后来"转学"了,登记本上那一行被划掉。这条不是怪谈,是旧事本身,适合放在物证里而不是讲出来。

建议:选 1、2、3、4 作为四个人讲的怪谈,"查寝"是应验的那一个(讲到一半,门真的被敲了);5 放进调查当线索;6 是物证。

## 机制怎么用

- 检定挂在选项标签上:`#check:insight:normal`、`#check:charm:easy`、`#check:strength:hard`,高潮处一个 `:red`。
- 每次失败必须改变点什么:恐惧涨、信任跌、某个选项消失、某人不再跟着你。失败没后果的地方不掷。
- 恐惧和信任用有界增量,不线性冲顶;恐惧每满 25 理智减 1(已配置)。
- 心声用 `#voice:reason` 这类行标签,每个技能一个口气,负责吐槽和暗示。
- 队友:每人一个想要的东西和一种害怕时的反应,害怕到一定程度会自己行动(跑、僵住、硬上),这是喜剧和危险的共同来源。
- 选项三类心里有数:故事型(去不去、应不应)、参数型(安抚、劝、硬撑)、无意义型(拌嘴,少放,只调节奏)。
- 正文双语 `{t("中文", "English")}`,id 全英文。

## 体量

- 一次通关 20 到 30 分钟,6 到 8 场戏,3 到 4 个结局。
- 四个主角共用场景,用分支做差异;技能差异靠成功率自然体现。
- 先写序段(怪谈之夜)跑通,再写破、急。
